# client-ts

TypeScript HTTP client helpers for OAN services.

Current scope:

- Registrar resource submission
- Registrar / Root / CDN / Discovery status access
- Registrar Root-authorization inspection
- Registrar capability-tag suggestion
- Discovery resource query
- Discovery query explanation
- Discovery authorized-domain inspection
- CDN package lookup
- Root resource-version lookup
- lifecycle observation across Registrar -> Root -> CDN -> Discovery
- lifecycle polling until Discovery visibility
